**Mistic** is a simple x86_64 freestanding C standard library used by [Mist](https://github.com/MistWorks/Mist), [Minit](https://github.com/MistWorks/Minit) and by all peace of MistWorks ecosystem in future

This training project made for learning how the PC works. Every bug fix and improvement are welcome, so _don't be shy to contribute_.
It uses MIT license so you can do anything with this code!

## What it have?
- Data types
- Memory module
- String module
- Integer math math
- Alignment macroses
- Formating
